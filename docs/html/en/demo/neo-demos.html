Neo Boing Platinum OS: the system

This is the main subject. Lite starts from an ISO image on BIOS and UEFI PCs and in QEMU, on x86_64 and AArch64. The code is public, under GPLv3.

What's new

ISO for BIOS and UEFIGRUB and Multiboot2, from USB or CD; CI boots it with SeaBIOS and OVMF.
The screen from UEFI GOP or VBEThe desk is drawn on the screen the boot loader sets up, even with no VGA card.
USB, PCI and ACPIUSB keyboard and mouse through xHCI and hubs, every PCI bus, power off through ACPI.
Genode on seL4: the trialAn unchanged Neo program runs as a Genode component; the neo_ports server carries messages.
First boot on real PCsThe BUILD-ISO guide, then Neo DOS on Genode and tiles on the desk.
AmigaOS in NeoAROS API and Shell, Zune, Wanderer, Directory Opus 5, FS-UAE and Janus-UAE in Arcade.
First Desk and the classic MacA retro theme modelled on System 7, with the Kelsidavis/System7 project as a reference; our own drawing, without Apple's names or fonts.
Games and apps in LiteFlatpak games, Arcade with DOSBox, ScummVM and RetroArch, FilmCraft, PhotoCraft, Album, HippoPlayer.
