Protection

Viruses? Locked in a box.

On today's systems a program you run can do anything you can. On Neo every program gets only what you give it.

Every program in its own box

A program sees only the files you give it through the open dialog. No access to the rest of the disk, the camera or the network without your permission.

The system cannot be infected

The OS is in ROM and is read-only. A virus cannot nest in the system, and a restart always returns it to a clean state.

Macros and documents

A document opens in a box without network access. A macro from an email cannot run anything outside that document.

The network under watch

Lock sees every outgoing packet per program and stops labelled files from being sent.

Honestly: the risk is not zero. No system can fully prevent fraud through a fake message, and there will be bugs in the code. That is why Renewal ships patches, and the damage from a successful attack stays locked in one box.
